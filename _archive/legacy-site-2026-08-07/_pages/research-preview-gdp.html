Research design

Respect the information calendar

The target is quarterly GDP growth; the predictors arrive daily or monthly. MIDAS keeps the high-frequency ordering while constraining the lag distribution to a small number of parameters.

Transform predictors

Apply returns, differences and stationarity checks across equities, rates, credit, FX, commodities and macro indicators.

Compress information

Use individual predictors or PCA factors while preserving mixed-frequency timing.

Estimate ADL–MIDAS

Fit exponential Almon weights and select autoregressive lag order using AIC.

Forecast recursively

Expand the estimation window and generate each forecast only with information available at that date.

Data engineering

Coverage, transformations and cross-asset structure are audited first

The 47-series panel spans equities, rates, commodities, FX and macro indicators with unequal histories. Coverage thresholds, transformations and alignment decisions are made visible before any forecasting comparison.

Benchmark set

Random Walk, AR, flat distributed lags, factor autoregressions, ADL, FADL and MIDAS variants are compared using RMSFE. Ratios below one indicate an improvement over Random Walk.

Forecast combination

Multiple signals can be combined with discounted MSFE weights, allowing models with smaller recent errors to receive more weight without using future outcomes.

Interpretability

The parameter has an economic meaning

A negative decay emphasizes recent observations; a positive decay gives more mass to older days. Plotting the estimated distribution makes unstable or implausible memory profiles visible instead of hiding them inside an optimizer.

Historical replication

High-frequency data helps only under the right specification

Daily leads materially improve several MIDAS variants, while the daily ADS macro index is especially informative in the replicated tables. The result is conditional: merely adding financial data does not guarantee a lower forecast error.

Original extension

Separate the lag block from the nowcast block

The standard specification applies one coefficient to historical lags and within-quarter leads. The Two‑β extension estimates distinct scaling and weight dynamics for past information and data already observed inside the target quarter.

Error anatomy

The recent ranking is driven by very few quarters

The post-COVID extension has only eight OOS forecasts. A quarter-level error heatmap makes it possible to see where a model misses, whether it systematically over- or under-predicts and how a small number of observations controls RMSFE.

What survives the replication

Leads and indicator choice matter more than complexity

  • Models with daily leads generally improve on no-lead variants.
  • ADS outperforms broad financial factors in the replicated tables.
  • Recursive OOS evaluation changes model rankings relative to in-sample fit.
  • Parsimonious AR and flat-ADL models dominate several richer variants in 2024–2025.

Limits

The extension fixes a restriction, not the whole forecast problem

Two‑β improves on standard MIDAS in the recent window but does not beat Random Walk. The eight-quarter OOS sample is sensitive to individual misses, and post-COVID factor relationships may be unstable. Longer windows, multiple horizons and a Two‑β FADL–MIDAS specification are natural next tests.

Implementation

Full pipeline, not a notebook-only result

The repository separates data loading, transformations, stationarity diagnostics, MIDAS estimation, benchmarks, recursive evaluation, paper-table replication and plotting. The generated figures and reports are preserved alongside the main notebook and Bloomberg-derived dataset.
